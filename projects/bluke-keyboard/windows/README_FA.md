# همگام‌سازی زبان Bluke از طریق بلوتوث

نسخه اندروید ۱.۲.۳ و ابزار ویندوز ۱.۲.۴ از همان گزارش خروجی استاندارد کیبورد (Report ID 1) استفاده می‌کنند. کد زبان در سه بیت بالایی بایت خروجی قرار می‌گیرد؛ شناسه گزارش و طول گزارش تغییر نمی‌کند.

1. APK اندروید ۱.۲.۳ را نصب کن. اگر امضای APK با نسخه قبلی متفاوت بود، ابتدا نسخه قبلی را حذف کن.
2. اتصال جفت‌شده فعلی بلوتوث را نگه دار؛ حذف Pair یا پاک‌کردن حافظه بلوتوث لازم نیست.
3. ابزار ویندوز ۱.۲.۴ را اجرا کن.
4. زبان ورودی ویندوز را عوض کن؛ چیدمان کلیدهای گوشی باید همگام شود.

ابزار ویندوز رابط کیبورد اندروید را با VID:PID برابر 2717:5070 (همان رابطی که در گزارش تشخیصی ویندوز دیده شد) پیدا می‌کند و کد زبان را در خروجی HID می‌فرستد. هات‌اسپات و وای‌فای لازم نیست.
