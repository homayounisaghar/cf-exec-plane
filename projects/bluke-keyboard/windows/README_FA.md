# پل زبان ویندوز برای Bluke

1. هات‌اسپات گوشی را روشن کن و ویندوز را به آن وصل کن.
2. Bluke را از طریق بلوتوث به ویندوز وصل کن و حالت Keyboard را باز کن.
3. برنامه BlukeLanguageBridge را اجرا کن.
4. برنامه شناسه زبان پنجره فعال را از ویندوز می‌خواند و فقط شناسه چیدمان را از شبکه محلی به گوشی می‌فرستد.

در صورت نیاز نشانی دروازه هات‌اسپات را دستی بده:

```powershell
.\BlukeLanguageBridge.exe --host 192.168.137.1
```

ارتباط محلی از درگاه 39472 استفاده می‌کند. متن تایپ‌شده، رویداد کلیدها و کلیپ‌بورد ارسال نمی‌شوند؛ تایپ همچنان فقط از Bluetooth HID عبور می‌کند.
