# ابزار همگام‌سازی زبان Bluke — نسخه تشخیصی ۱.۲.۳

این نسخه همان اتصال بلوتوث HID را استفاده می‌کند و برای پیدا کردن علت شناسایی‌نشدن گزارش زبان، رابط‌های HID ویندوز را با جزئیات چاپ می‌کند.

1. اتصال فعلی Bluke را در ویندوز و گوشی نگه دار؛ هیچ دستگاهی را حذف یا دوباره Pair نکن.
2. فایل ZIP را باز کن و `BlukeLanguageBridge.exe` را اجرا کن.
3. اگر رابط اختصاصی پیدا شود، برنامه پیام `Bluke Bluetooth HID output collection found` را نشان می‌دهد و همگام‌سازی زبان را شروع می‌کند.
4. اگر پیدا نشود، تعداد رابط‌های HID و اطلاعات رابط‌های مرتبط (نام محصول، صفحه/کاربرد، طول گزارش و مسیر کوتاه دستگاه) چاپ می‌شود. از پنجره عکس بگیر یا متن را کپی کن و بفرست.

این نسخه تشخیصی است؛ هیچ تنظیم بلوتوث، Pairing یا درایور ویندوز را تغییر نمی‌دهد. هات‌اسپات و وای‌فای لازم نیست.
