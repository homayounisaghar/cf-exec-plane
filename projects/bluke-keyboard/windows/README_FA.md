# همگام‌سازی زبان Bluke از طریق بلوتوث

1. نسخه جدید Bluke را روی گوشی نصب کن.
2. در ویندوز، دستگاه بلوتوثی قدیمی Bluke را از فهرست دستگاه‌های Pair شده حذف کن؛ سپس از داخل Bluke دوباره به ویندوز وصل شو تا گزارش HID جدید شناسایی شود.
3. حالت Keyboard را در Bluke باز نگه دار.
4. فایل `BlukeLanguageBridge.exe` را اجرا کن.
5. زبان ورودی ویندوز را در هر پنجره‌ای عوض کن؛ چیدمان کیبورد گوشی باید همگام شود.

این برنامه فقط شناسه زبان فعال را از ویندوز می‌خواند و آن را با گزارش خروجی اختصاصی HID از همان اتصال بلوتوث می‌فرستد. هات‌اسپات، وای‌فای، نشانی شبکه و نصب جداگانه دات‌نت لازم نیست.

متن تایپ‌شده، کلیدها و محتوای کلیپ‌بورد از این مسیر منتقل نمی‌شوند؛ تایپ همچنان با Bluetooth HID انجام می‌شود.
