# همگام‌سازی زبان Bluke از طریق همان اتصال HID

نسخه اندروید ۱.۲.۶ و ابزار ویندوز ۱.۲.۸ از **گزارش خروجی استاندارد کیبورد، Report ID 1** استفاده می‌کنند؛ رابط اختصاصی تازه‌ای به توصیف‌گر اضافه نشده است.

ویندوز با تغییر موقت Scroll Lock، تعداد زوجی از تغییرات وضعیت چراغ را می‌فرستد:
- ۲ تغییر: انگلیسی
- ۴ تغییر: فرانسوی
- ۶ تغییر: آلمانی
- ۸ تغییر: روسی
- ۱۰ تغییر: فارسی

تعداد زوج است؛ بنابراین وضعیت نهایی Scroll Lock به حالت اولیه برمی‌گردد. اندروید تغییرات را از همان گزارش LED دریافت و پس از پایان رشتهٔ پالس‌ها چیدمان را عوض می‌کند.

۱. APK اندروید ۱.۲.۶ را نصب کن.
۲. پیام تازه‌سازی سرویس بلوتوث را تأیید کن تا HID با توصیف‌گر به‌روز دوباره ثبت شود.
۳. اتصال جفت‌شدهٔ فعلی را نگه دار؛ حذف Pair یا وای‌فای لازم نیست، مگر اینکه میزبان هنوز توصیف‌گر قدیمی را نگه داشته باشد.
۴. ابزار ویندوز ۱.۲.۸ را اجرا کن و زبان ورودی ویندوز را تغییر بده.

ابزار ویندوز فقط یک فایل EXE مستقل است و برای ارسال زبان از نوشتن مستقیم روی رابط محافظت‌شدهٔ کیبورد استفاده نمی‌کند.
