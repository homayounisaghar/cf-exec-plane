# پل زبان ویندوز برای Bluke

## راه‌اندازی

1. هات‌اسپات گوشی را روشن کن و ویندوز را به آن وصل کن.
2. در گوشی Bluke را باز کن و اگر مجوز «دستگاه‌های نزدیک» خواست، اجازه بده.
3. Bluke را از طریق بلوتوث به ویندوز وصل کن و حالت Keyboard را باز کن.
4. برنامه `BlukeLanguageBridge.exe` را اجرا کن.
5. در نوار بالای کیبورد گوشی باید وضعیت `LAN: Listening` دیده شود؛ پس از اتصال ویندوز، به `LAN: Windows connected` تغییر می‌کند.

برنامه به‌طور خودکار دروازه شبکه وای‌فای گوشی را انتخاب می‌کند و رابط‌های شناخته‌شده VPN را نادیده می‌گیرد. آدرس مقصد را هم در پنجره نشان می‌دهد.

اگر لازم شد آدرس هات‌اسپات را دستی بدهی، در PowerShell از همان پوشه اجرا کن:

```powershell
.\BlukeLanguageBridge.exe --host 10.43.213.105
```

به‌جای نمونه بالا، نشانی دروازه‌ای را بگذار که در خروجی `ipconfig` یا `Get-NetIPConfiguration` برای Wi-Fi دیده می‌شود.

ارتباط محلی از درگاه 39472 استفاده می‌کند. متن تایپ‌شده، رویداد کلیدها و کلیپ‌بورد ارسال نمی‌شوند؛ تایپ همچنان فقط از Bluetooth HID عبور می‌کند.
